# 目标创建与需求澄清 v0.1

状态：首版产品方案已确认。本文定义用户从自然语言目标进入路线生成前的交互，不要求用户选择领域。

## 1. 设计目标

用户可以从一句自然描述开始。Agent 负责提取已有信息、复用账号设置、识别矛盾并追问最少的关键事实；澄清不是固定问卷，也不以收集所有可能信息为结束条件。

用户确认的是“我想实现什么、如何判断成功、有哪些现实限制”，不是 Agent 的内部领域分类。信息不足但不影响安全与基本可行性时，Agent 应明确假设并继续，不能为了填满字段持续追问。

## 2. 最小目标档案

| 部分 | 进入路线生成前的要求 | 缺失时如何处理 |
| --- | --- | --- |
| 目标结果 | 必须能描述希望发生的结果 | 追问结果，不接受只有“坚持、提升、学习”等活动词 |
| 成功标准 | 至少一项可观察标准，或明确的诊断阶段 | 帮用户提出候选标准；无法判断基线时先规划诊断 |
| 当前基础 | 可以是已知事实，也可以明确为未知 | 未知不阻塞，但路线要包含评估或试运行 |
| 时间边界 | 固定日期、弹性周期或持续维持三者之一 | 不强迫用户虚构日期；记录“无固定期限”及其含义 |
| 可用投入 | 优先复用账号的共享时间预算 | 尚未设置时才询问大致可用时间；不能重复分配给多个目标 |
| 硬约束 | 已知的健康、安全、资源、地域、成本或依赖限制 | 只询问与当前目标相关的限制；关键安全信息未解决时不生成承诺性方案 |
| 推进偏好 | 可选，例如节奏、方法、是否愿意测评 | 缺失不阻塞，路线比较时提供不同取舍 |
| 目标关系 | 默认按独立目标评估；需要复用成果或形成依赖时明确对象 | 在计划启用前完成关联确认，不要求用户理解任务图 |

目标档案中的每条信息标注为：用户事实、Agent 推断、待确认假设或未知。Agent 推断不能自动升级为用户事实。

## 3. 追问策略

每轮优先提出一个问题组，包含一至三个彼此相关的短问题。问题按以下顺序选择：

1. 消除会导向完全不同方案的歧义。
2. 补足成功标准、时间或投入等可行性条件。
3. 补足安全和硬约束。
4. 获取能显著改善路线差异的信息。
5. 偏好和细节可以延后到路线微调或执行阶段。

Agent 不重复询问账号设置或对话中已有的事实，不询问内部领域，不要求用户精确回答其本来就不知道的信息。每个非显而易见的问题可以用一句话说明用途，并提供“不确定，由 Agent 先建议”入口。

正常目标建议在一至三轮内形成档案草稿。第二轮后仍存在非关键缺口时，优先展示草稿、假设和待补项，让用户编辑或继续补充；轮数是体验目标，不是强制截断复杂目标的业务规则。

## 4. 何时停止澄清

同时满足以下条件时进入目标档案确认：

- 目标结果不存在未解决的核心歧义。
- 成功标准可检查，或者已明确先执行诊断阶段。
- 时间边界和可用投入足以比较至少两种真实路线；只有一种可行时可以明确说明。
- 没有互相矛盾的已确认事实。
- 没有阻止安全规划的关键未知项。
- 所有仍采用的假设都能在档案中清楚展示。

达到条件后 Agent 不再为了完善画像追加问题。用户确认档案版本后才能生成正式路线；用户修改关键字段时，旧路线标记为过期。

## 5. 页面交互

创建目标页只保留一个主要输入：“你最近想完成什么目标？”用户可以一次输入长描述，也可以从一句话开始。发送后进入对话式澄清。

页面侧边或移动端抽屉持续展示目标档案草稿：

- 想达到的结果
- 如何判断成功
- 当前情况
- 时间和可用投入
- 限制与依赖
- Agent 正在采用的假设

每项都可直接编辑。主按钮在未就绪时为“继续补充”，就绪后变为“确认目标并查看方案”。如果仍有可跳过项，按钮附近明确写出将采用的假设。

## 6. 特殊情况

- **目标过大**：先澄清近期可验证结果，再把长期方向保留为背景，不能直接生成无限期任务列表。
- **包含多个独立结果**：Agent 建议拆成多个目标并说明时间协调影响，由用户确认是否拆分。
- **目标互相冲突**：展示冲突事实和可能取舍，不自行降低其中一个目标。
- **用户不知道基线**：创建短期诊断任务或试运行阶段，不把猜测写成基线。
- **持续型目标**：使用周期性成功标准和回顾频率，不强迫填写完成日期。
- **健身健康风险**：询问与执行安全直接相关的限制；Agent 不诊断疾病，存在明显风险时限制建议范围。
- **用户要求立即生成**：若只有非关键缺口，可以带假设进入档案确认；存在结果歧义或安全阻断时仍需最少追问。

## 7. 验收场景

- 用户输入“我想学英语”，Agent 不询问领域，而是询问使用场景、期望结果和可用时间。
- 账号已有每周可用时间时，新目标不重复询问总时间，并在路线中展示对其他目标的占用影响。
- 用户没有考试日期，可以选择弹性周期，不被迫填写虚假截止日期。
- 用户不知道当前水平，目标档案明确记录未知，并在路线中包含诊断阶段。
- 用户两次陈述发生冲突时，Agent 请求澄清并保留修正记录，不同时把两条都当作事实。
- 关键字段齐备后，Agent 主动展示档案并停止继续采访。
